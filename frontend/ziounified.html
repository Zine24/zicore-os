MODULO DEL ECOSISTEMA ZICORE

ZIO UNIFIED

Plataforma que integra los sistemas del ecosistema ZICORE: control de fabricacion, vision por camara, firmware Marlin, control CNC y visualizacion en escritorio en una sola interfaz.

▶ Abrir Master Creator Launch Pad
ZIO Unified es el modulo de integracion del ecosistema ZICORE. Combina streaming de camara ESP32-S3, control de firmware Marlin, gestion de nodos CNC y un visualizador de escritorio en un solo sistema coherente.

Repositorio: github.com/Zine24/ZioUnified

Modulos Integrados

ZiCAM ESP32-S3
Streaming de video MJPEG, grabacion microSD y panel web. Camara OV3660 con IMU MPU6050 integrada.
Firmware
🖥
Visualizador Desktop
Layout HTML de 3 columnas. Feed de camara en vivo, panel de datos IMU y control de impresion.
Desktop

Firmware Marlin
Build de Marlin con soporte ZiMMU. Control de unidad multi-material e integracion de nodos CNC. Proyecto PlatformIO.
Firmware

App Android
Control nativo Android. Monitoreo de impresion, vista de camara y control remoto desde el telefono.
Mobile
🔧
ZiMMU CNC
Controlador de nodos CNC. Gestion de unidad multi-material, cambio de herramienta y control de coordenadas.
CNC
📡
Serial Bridge
Puente serial Python para comunicacion escritorio ↔ firmware. Scripts de build y deployment incluidos.
Bridge
